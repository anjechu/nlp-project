# Google Embedding Projector Export Guide

## Overview

The `export_to_projector()` function exports embeddings and metadata to TSV files compatible with Google's Embedding Projector (https://projector.tensorflow.org/).

## Function Signature

```python
def export_to_projector(
    embeddings, 
    dataframe, 
    output_dir=".", 
    vectors_filename="vectors.tsv", 
    metadata_filename="metadata.tsv"
)
```

## Parameters

- **embeddings** (numpy.ndarray): Array of shape (n_samples, n_dimensions) containing the embedding vectors
  - Generated by `SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')`
  - Typically 384-dimensional vectors

- **dataframe** (pandas.DataFrame): DataFrame containing at least these columns:
  - `text`: The original text for each sample
  - `topic_id`: Topic cluster assignment for each sample

- **output_dir** (str, optional): Directory where TSV files will be saved. Default: current directory

- **vectors_filename** (str, optional): Name for the vectors file. Default: "vectors.tsv"

- **metadata_filename** (str, optional): Name for the metadata file. Default: "metadata.tsv"

## Output Files

### vectors.tsv
- Tab-separated values with NO header
- Each row contains the embedding vector for one sample
- Format: `dim1\tdim2\tdim3\t...\tdim384`

### metadata.tsv
- Tab-separated values WITH header
- Contains three columns:
  - `text`: Original text (cleaned of tabs/newlines)
  - `topic_id`: Topic cluster ID
  - `language`: Detected language (Chinese, Japanese, or English)

## Language Detection

The function uses a simple lambda function to detect language:

```python
detect_language = lambda text: (
    'Chinese' if any('\u4e00' <= c <= '\u9fff' for c in str(text)) else
    'Japanese' if any('\u3040' <= c <= '\u30ff' or '\u31f0' <= c <= '\u31ff' for c in str(text)) else
    'English'
)
```

**Detection Rules:**
- If text contains Chinese characters (U+4E00 to U+9FFF) → `Chinese`
- Else if text contains Japanese characters (Hiragana/Katakana) → `Japanese`
- Otherwise → `English`

## Usage Examples

### Example 1: Basic Usage

```python
from nlp import NLPProcessor, export_to_projector
import pandas as pd

# Process comments
processor = NLPProcessor()
processor._ensure_models_loaded()

# Your text data
texts = ["This game is amazing!", "这个游戏很好玩", "このゲームは素晴らしい"]
df = pd.DataFrame({'text': texts, 'topic_id': [1, 1, 2]})

# Generate embeddings
embeddings = processor.embedder.encode(texts)

# Export to projector format
result = export_to_projector(embeddings, df, output_dir='./projector_output')

print(f"Exported {result['num_samples']} samples")
print(f"Vectors: {result['vectors_path']}")
print(f"Metadata: {result['metadata_path']}")
```

### Example 2: After Full Processing

```python
from nlp import NLPProcessor, export_to_projector
import pandas as pd
import json

# Process a file through the full pipeline
processor = NLPProcessor()
result = processor.process_file('input.json', 'output.json')

# Load the processed data
with open('output.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# Reconstruct dataframe and embeddings from topics
all_texts = []
all_topic_ids = []
for topic in data['topics']:
    for text in topic['sample_texts']:
        all_texts.append(text)
        all_topic_ids.append(topic['topic_id'])

df = pd.DataFrame({'text': all_texts, 'topic_id': all_topic_ids})

# Regenerate embeddings for these texts
processor._ensure_models_loaded()
embeddings = processor.embedder.encode(all_texts)

# Export
export_to_projector(embeddings, df, output_dir='analysis')
```

### Example 3: Custom Output Location

```python
from nlp import export_to_projector

# Export to a specific directory with custom filenames
result = export_to_projector(
    embeddings=my_embeddings,

    metadata_filename='game_metadata.tsv'

```

## Visualizing with Google Embedding Projector

### Step 1: Export your data
```python
export_to_projector(embeddings, df, output_dir='./viz')
```

### Step 2: Visit the Projector
Go to https://projector.tensorflow.org/

### Step 3: Load your data
1. Click "Load" button in the left sidebar
2. Select "Choose file" under "Load data"
3. Upload `vectors.tsv` first
4. Upload `metadata.tsv` second
5. The projector will automatically link them

### Step 4: Explore
- **Color by**: Select `language` or `topic_id` from dropdown
- **3D/2D**: Toggle between views
- **Algorithm**: Try PCA, t-SNE, or UMAP
- **Search**: Find specific texts
- **Isolate**: Select points to see their metadata

## Visualization Tips

### Color by Language
```
Settings → Color by → language
```
This will show you:
- Chinese samples in one color
- Japanese samples in another color
- English samples in a third color

### Color by Topic
```
Settings → Color by → topic_id
```
This will show you different topic clusters in different colors.

### Find Similar Comments
1. Click on any point to see its text
2. Find its neighbors in the embedding space
3. They should have similar meanings

### Dimensionality Reduction
- **PCA**: Fast, preserves global structure
- **t-SNE**: Slow, preserves local structure, great for clusters
- **UMAP**: Balance between PCA and t-SNE

## Troubleshooting

### Error: "Embeddings length must match DataFrame length"
**Solution**: Ensure your embeddings array has the same number of rows as your DataFrame.

```python
print(f"Embeddings: {len(embeddings)}")
print(f"DataFrame: {len(df)}")
# They must match!
```

### Error: "DataFrame missing required columns"
**Solution**: Ensure your DataFrame has both 'text' and 'topic_id' columns.

```python
print(df.columns)
# Must include: ['text', 'topic_id', ...]
```

### Files are too large
**Solution**: Filter your data first or use a random sample.

```python
# Sample 1000 random points
sample_indices = np.random.choice(len(df), size=1000, replace=False)
df_sample = df.iloc[sample_indices]
embeddings_sample = embeddings[sample_indices]

export_to_projector(embeddings_sample, df_sample)
```

### Upload fails on projector.tensorflow.org
**Possible causes**:
1. File too large (>100MB) - sample your data
2. Invalid TSV format - check for tabs in text
3. Mismatched row counts - verify lengths match

## Return Value

The function returns a dictionary with:

```python
{
    'vectors_path': '/path/to/vectors.tsv',
    'metadata_path': '/path/to/metadata.tsv',
    'num_samples': 1000,
    'dimensions': 384,
    'languages': {'Chinese': 300, 'Japanese': 250, 'English': 450}
}
```

## Performance Notes

- **File sizes**: ~1KB per sample for 384-D vectors
- **Export time**: < 1 second for 1000 samples
- **Memory**: Minimal (streaming write for large datasets)

## Integration with NLP Pipeline

The function is designed to work seamlessly with the existing NLP processing pipeline:

```python
# In your processing workflow
processor = NLPProcessor()

# 1. Process comments
result = processor.process_file('input.json', 'output.json')

# 2. Extract embeddings during processing
# (Store embeddings when they're generated)
embeddings = processor.embedder.encode(df['text'].tolist())

# 3. Export for visualization
export_to_projector(embeddings, df, output_dir='viz')
```

## Advanced: Filtering Before Export

```python
# Only export high-density topics
high_density_topics = df[df['topic_id'].isin([1, 2, 3, 5])]
high_density_embeddings = embeddings[df['topic_id'].isin([1, 2, 3, 5])]

export_to_projector(high_density_embeddings, high_density_topics)
```
